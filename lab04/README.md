### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*
```
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```


**Ответ:**

* Выводится: 40000 7232
* Объяснение: x = 40000, x + x = 80000, но это выходит за диапазон unsigned short(65536), поэтому 80000 делится на 65536 и берется остаток 14464 - это значение y. y = y - x дает 14464 - 40000 = -25536, мы выходим за границы в минус, берется остаток по кольцу и получается 40000 (-25536 + 65536). z = x * 2 тоже дает переполнение и получается 14464, а 14464 / 2 = 7232.


### Задание 6 **(2)**

*Объясните работу фрагмента программы на С++. Если имеет место переполнение, 
то требуется найти точный ответ до запуска программы, а только потом сверить его с выводом.
В отчете надо привести вычисления, приводящие к ответу.*
```
std::cout << 2000000000 + 1000000000 << std::endl;
std::cout << 2000000000U + 1000000000U << std::endl;
std::cout << 2500000000U + 2500000000U << std::endl;
std::cout << 2500000000LL + 2500000000LL << std::endl;
std::cout << 20000U * 200000U << std::endl;
std::cout << 200000U * 200000U << std::endl;
```


**Ответ:**

* Выводится:
	-1294967296
	3000000000
	705032704
	5000000000
	4000000000
	1345294336
* Объяснение:
* В первой строке 2000000000 + 1000000000 получается 3000000000, но оно выходит за диапозон знакового int (2147483647), поэтому из-за переполнения по кольцу число уходит в минус.
* Во второй строке благодаря суффиксу U тип становится беззнаковым unsigned int (4294967295), поэтому 3000000000 помещается и выводится.
* В третьей строке 2500000000U + 2500000000U получается 5000000000, мы снова выходим за лимит (4294967296), 5000000000 делится на 4294967296 и берется остаток =  705032704.
* В четвертой строке суффикс LL дает тип long long, его диапазона хватает, и сумма 5000000000 выводится.
* В пятой строке 20000U * 200000U дает 4000000000, что входит в лимит unsigned int, поэтому выводится.
* В шестой строке 200000U * 200000U дает 40000000000, это переполняет unsigned int, 40000000000 делится на 4294967296 и берется остаток 1345294336.
